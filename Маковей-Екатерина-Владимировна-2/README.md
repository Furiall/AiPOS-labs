## Описание

Клиент-серверное приложение на UDP (порт 666).

- **Сервер** (`server.cpp`) принимает байты от клиента, накапливает группы по 64 байта, считает частоты символов и отправляет ответ в формате `<...>`. Если в группе меньше 3 различных символов — сессия завершается с ошибкой.
- **Клиент** (`client.cpp`) отправляет текст по Enter или PgDn, принимает ответы в отдельном потоке, ведёт лог `udp-client.log`. Выход — Esc, `quit` или `exit`. При завершении шлёт серверу `QUIT`.

## Файлы

- `server.cpp` — UDP-сервер
- `client.cpp` — UDP-клиент
- `run.bat` — сборка и запуск (опционально)
